# 🔋 Battery Test Data Automation Tool

Python-based tool for automated analysis of battery cycling data, including capacity degradation and efficiency evaluation.

---

## 🚀 Features

- Automated processing of battery test data (CSV)
- Capacity fade analysis across cycles
- Coulombic efficiency calculation
- Voltage vs time visualization
- Automated report generation

---

## 🛠 Tech Stack

- Python
- pandas
- matplotlib

---

## ▶️ How to Run

```bash
pip install pandas matplotlib
python main.py
